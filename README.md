# PikoVK 1.3.23

Лёгкий WebView-браузер с домом на VK для Android 8.0+ (Kotlin, без серверной части
— всё работает локально на устройстве).

Возможности:

- **Движок расширений** — CSS/JS внедряются до кода страницы
  (`WebViewCompat.addDocumentStartJavaScript`): блокировка рекламы, тёмная тема,
  скачивание медиа, твики ленты. Всё включается тумблерами и применяется без
  перезапуска приложения.
- **Вкладка «Музыка»** (1.3.23) — собственный плеер вне страниц VK по образцу
  VK Music Player: «Моя музыка», поиск, плейлисты, обложки, значки битрейта,
  шаффл/повтор, скачивание mp3 и .ts.
- **Мультиаккаунт** — до 3 независимых сессий VK, переключение без перелогина.
- **Фоновые уведомления** — опрос «Ответов» (реакции, комментарии, ответы) и
  «Сообщений» (мессенджер) с cookie своей сессии; уведомления в шторке и на
  экране блокировки, тап по сообщению открывает мессенджер.
- **Фоновое воспроизведение** — процесс держит foreground-служба, рендерер
  WebView не приглушается, процессор не засыпает в паузе между треками,
  страница «считает себя видимой» (таймеры плеера не троттлятся); медиашторка
  с кнопками и гарнитурой; звук при заблокированном экране.
- **Переключение мобильной/полной версии** — UA, хост и версионные куки всегда
  согласованы, есть защита от пинг-понга редиректов.

**Принцип: принудительных блокировок в приложении нет.** Контент, VK Mini Apps,
картинки, видео и аудио загружаются как есть; в адресной строке можно открыть
любой сайт. Единственная блокировка — расширение «Блокировка рекламы» (с 1.3.16
включено по умолчанию по прямому решению владельца и полностью выключается
одним тумблером).

## Настройки

Все настройки — в приложении: кнопка «шестерёнка» (настройки) на нижней панели.
Изменения, влияющие на WebView (расширения, UA, версия сайта), применяются после
возврата в браузер; служебные — сразу.

### Интерфейс

| Переключатель | По умолчанию | Что делает |
|---|---|---|
| Адресная строка сверху (полный режим) | выкл. | полный режим с адресной строкой; по умолчанию минимализм — только нижняя панель |

### Расширения

| Переключатель | По умолчанию | Что делает |
|---|---|---|
| Блокировка рекламы | **вкл.** (с 1.3.16) | прячет рекламные контейнеры и карточки ленты, режет рекламные домены и счётчики, отменяет переходы по рекламным ссылкам. Подробно — раздел «Блокировка рекламы: как работает» |
| Тёмная тема | вкл. | перед загрузкой выставляются родные куки темы VK (remixdark_color_scheme / remixcolor_scheme_mode) — VK рисует свою настоящую тёмную тему; CSS-инверсия остаётся запасным механизмом. Тема приложения тоже всегда тёмная. Повторное включение тумблера применяет куки заново |
| Скачивание медиа | вкл. | долгое нажатие на фото → «Скачать изображение»; клик по прямой ссылке mp4/mp3/pdf → «Скачать файл»; всё через системный DownloadManager |
| Твики ленты | выкл. | скрывает стори, делает посты компактнее |

### Версия VK и User-Agent

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Всегда полная версия vk.ru | выкл. | каждый запуск открывается в полной версии (там работают плейлисты Музыки); после запуска кнопку версии можно переключить — выбор действует до следующего запуска |
| User-Agent (кнопка «Выбрать») | Android (как реальное устройство) | 6 пресетов: Android (реальное устройство), Android (Chrome 130, Pixel), iPhone (Safari), Windows (Chrome), macOS (Safari), Linux (Firefox) + «Свой вариант» (ручной ввод). Пресет действует в мобильном режиме; полная версия всегда использует десктопный UA |

Кнопка «монитор/телефон» на нижней панели — переключение версии на лету:
UA и хост (m.vk.ru ↔ vk.ru) меняются ТОЛЬКО вместе, иначе VK возвращает
редиректом на «свою» версию. Перед загрузкой записываются согласованные
версионные куки (remixforce_full=2 + remixshow_fvbar=1 в полную, стирание
мобильных маркеров — в мобильную); авторизационные куки не трогаются.

### Медиа

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Фоновое воспроизведение аудио и видео | вкл. | при свёрнутом приложении и погашенном экране работают четыре механизма: foreground-служба держит процесс (1.3.10), приоритет рендерера (1.3.14), wake-lock в паузе между треками (1.3.14), страница «считает себя видимой» — таймеры плеера не троттлятся (1.3.18/1.3.22). В шторке — медиашторка с кнопками и метаданными (1.3.21), команды гарнитуры/Bluetooth |
| Кнопка «Отключить оптимизацию батареи» | — | системный диалог исключения из Doze; без него Android может приостановить сеть при подгрузке следующего трека. Относится и к фоновому воспроизведению, и к уведомлениям |

### Фоновые уведомления

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Реакции, комментарии, ответы | выкл. | опрос страницы «Ответы» VK с cookie активной сессии; каналы «Реакции», «Комментарии», «Ответы» |
| Личные сообщения (мессенджер) | выкл. | второй контур опроса (m.vk.ru/im): счётчики непрочитанных диалогов, уведомление только при РОСТЕ счётчика; тап открывает мессенджер |
| Интервал опроса | 60 с | 30 / 60 / 120 / 300 секунд, общий для обоих контуров |

Служба живёт, пока включён хотя бы один тумблер; при первом включении
запрашивается разрешение на уведомления (Android 13+). После перезагрузки
устройства служба возобновляется. Опрашивается только активный профиль,
данные никуда не отправляются.

### Профили и диагностика

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Профили (кнопка на нижней панели) | слот 1 | до 3 сессий без перелогина; снимки cookie vk.ru и id.vk.ru, localStorage очищается при переключении; долгое нажатие — выход из аккаунта |
| Снифер ссылок (logcat PikoVK-Link) | вкл. | каждый адрес с разбором параметров — в журнал logcat (клики, запросы, спа-переходы, скачивания); остаётся только на устройстве, но адреса могут содержать токены |

### Управление с нижней панели

назад / вперёд / дом / обновление · «монитор/телефон» (версия) · профиль ·
«нота» (вкладка «Музыка») · настройки.

### Среда выполнения

- Android 8.0+; системный WebView должен быть свежим: на старых (например,
  WebView 69 2018 года) `addDocumentStartJavaScript` недоступен и расширения
  не внедряются — в logcat по фильтру `PikoVK` видно предупреждение
  «WebView слишком стар — обновите».
- Службы: `NotifyService` (foregroundServiceType `specialUse` — поэтому интервал
  опроса не ограничен 6 часами, как dataSync на Android 14) и `PlaybackService`
  (`mediaPlayback`). С 1.3.22 служба воспроизведения запускается упреждающе,
  пока приложение на экране (требование Android 17 «Background audio
  hardening») — иначе звук при заблокированном экране глохнет.

## Сборка

1. Android Studio: `File → Open` → папка `PikoVK`, дождаться синхронизации
   Gradle, `Run ▶`.
2. Консоль: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.
3. Release: `./gradlew assembleRelease` (minify выключен).

Правила кода (проверяются при каждой доработке): в Kotlin запрещены `!!`,
`?:`, `?.` и блочные комментарии `/* */` — только явные проверки null и
строчные комментарии `//`; каждый рекламный селектор в `ExtensionEngine`
снабжён комментарием с пояснением.

## Блокировка рекламы: как работает

Внутри «Блокировки рекламы» — независимые уровни; каждый точный, все
fail-open (признак не совпал — ничего не прячется, контент не страдает):

1. **Селекторы помеченных блоков** — то, что VK сам помечает в разметке:
   `#ads_left`, `[data-ad-view]`, `._ads_promoted_post_data_w`, промо Музыки
   и сторис; баннеры промо мини-приложений в ленте (`.apps_feedRightAppsBlock`,
   `.NewMiniAppsRightBlock__root`, `#feed_mini_apps_recomm`,
   `.feedAssistancePromoButtonInstallApp` + семейные маски
   `[class*="apps_feedRightAppsBlock"]`, `[class*="NewMiniApps"]`).
2. **Штатные флаги VK** (`noAds`, `no_ads`, `hide_ad`, …) — страница сама не
   создаёт рекламные блоки.
3. **Маркеры внутри карточек** (1.3.17) — плашка `.ads_mark`,
   `.wall_marked_as_ads`, пункт меню `ad_info.php`, `adsite_`/`post_ad_data`
   в onclick, атрибут видеорекламы `data-mt-video-hls`: карточка прячется
   целиком.
4. **Ссылочный уровень** — карточка, ведущая через рекламный редиректор
   (`rv.mail.ru`, `adfox.ru`, `mradx.net`, `ad.mail.ru`) или на лид-форму
   (`type=leadform`), прячется целиком, включая ссылки, закодированные в
   `away.php?to=`.
5. **Содержательный уровень** (2026-11-11, доработка-12) — карточка промо
   мини-приложения в ленте ищется по содержимому, а не по классам: ссылка на
   `/app<цифры>`, iframe `vk-apps.ru`, метка-лист «Реклама». Только страницы
   ленты, только карточки с картинкой, посты/сторис/открытые мини-аппы не
   трогаются.
6. **Сетевой уровень** — честный HTTP 451 для сторонних счётчиков (Mail.ru,
   Яндекс, Mediascope: `top-fwz1.mail.ru`, `mc.yandex.ru`, `tns-counter.ru`, …),
   рекламного CDN `mradx.net`, эндпоинтов выдачи рекламы VK (`/ads_rotate`,
   `al_feed.php?ads_section`, `al_video.php?act=ads_stat`), документа общего
   рендерера лид-форм (`/app51478948`), пикселя `/rtrg`, `stats.vk-portal.net`.
7. **Навигационный уровень** — переход по рекламной ссылке отменяется до
   загрузки, с коротким уведомлением «Рекламная ссылка заблокирована».
8. **Заглушка Adman** — рекламный SDK плеера подменяется на видеостраницах
   (vkvideo.ru, `/video*`, `/clip*`): видео стартует без пре-ролла; на аудио
   не работает (иначе задерживала старт следующего трека).

Сознательно НЕ трогается (риск для контента): `vk.cc`, голые `vk.ru`/`vk.com`,
широкие маски вида `[class*="ad-"]`, пути vk.ru кроме выделенных рекламных.
Если VK поменяет разметку — правится `ExtensionEngine.AD_BLOCK_JS`.

## Известные ограничения

- Одна вкладка браузера (мультитаб поверх `MainActivity` позже); «Музыка» —
  отдельная вкладка-плеер.
- Уведомления — опрос, а не push: задержка равна интервалу (30–300 с);
  парсер эвристический, при смене разметки VK правятся константы
  `NotifyService` / `ImPoller`; опрашивается только активный профиль.
- Если VK упорно возвращает мобильную версию, после двух отскоков защита
  обрывает цикл: кнопка честно возвращается в «мобильная» (с тостом).
- Переключение версии пересобирает WebView (гарантированная запись кук):
  страница перезагружается, позиция скролла и история «Назад» не сохраняются.
- Автозапуск медиа разрешён (плейлист играет без тапов) — теоретически
  страница может запустить видео сама; в веб-VK это практически не встречается.
- Закрытие приложения из «недавних» уничтожает WebView вместе со звуком
  (ограничение WebView-архитектуры). На MIUI/Huawei дополнительно включите
  «Автозапуск» и «Батарея → Без ограничений» для PikoVK.
- При включённой блокировке страницы лид-форм (`/app51478948#?type=leadform`)
  недоступны намеренно: чтобы открыть — выключите тумблер на время.
- Скачивание HLS-аудио даёт .ts без конвертации в mp3 (файлы играют
  VLC / MX Player); конвертация не делается.
- Селекторы рекламы и твиков, парсер уведомлений — эвристические: VK меняет
  разметку, правится в одном месте (`ExtensionEngine`, константы парсеров).

## Безопасность и приватность

- Камера и микрофон запрещены (`onPermissionRequest → deny`) — приложение
  никогда не получает доступ к записи.
- Mixed content и cleartext (http) запрещены на уровне Android.
- Cookies третьих сторон включены (нужны VK ID и Mini Apps).
- `allowBackup="false"` — сессии не уходят в бэкапы.
- Фоновые опросы запрашивают только страницу «Ответы»/«Сообщений» с cookie
  вашей собственной сессии; данные никуда не отправляются.
- Снифер ссылок пишет только в logcat устройства; при необходимости
  выключается тумблером.
